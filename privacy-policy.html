버리는 날 - 분리수거 요일 알림
개인정보처리방침

시행일: 2026년 9월 8일

버리는 날 - 분리수거 요일 알림(이하 “앱”, 기기 표시 이름: “버리는 날”)은 사용자의 개인정보를 외부 서버로 수집하거나 제3자에게 제공하지 않습니다. 앱은 지역별 배출 일정을 확인하고 배출 기록을 관리하는 기능을 오프라인으로 제공합니다.

1. 앱이 처리하는 정보

앱은 다음 정보를 사용자의 기기에 저장합니다.

  • 사용자가 직접 선택한 시·도, 시·군·구 및 동네
  • 구역별 배출 일정 선택값
  • 알림 시간과 기록 표시 설정
  • 배출 완료 또는 건너뜀 기록
  • 분석 기능 사용 여부 설정

위 정보는 Room 데이터베이스와 Android DataStore에 저장되며 앱이 개발자의 서버로 전송하지 않습니다. 다만 Android 및 기기 백업 설정에 따라 운영체제의 백업·복원 또는 기기 간 이전 대상이 될 수 있습니다. 백업은 사용 중인 운영체제와 백업 서비스의 설정 및 정책을 따릅니다. 앱은 기기의 GPS 위치나 주소록을 읽지 않습니다.

2. 권한 사용

앱은 사용자가 배출 알림 시간을 선택한 경우에만 알림 권한을 요청합니다. 알림 권한은 사용자의 기기에서 배출 일정 알림을 표시하기 위해서만 사용됩니다. Android 13 이상에서 요청하는 선택 권한이며, 허용하지 않아도 일정 조회와 배출 기록 기능을 이용할 수 있습니다. 알림 허용 여부는 휴대전화 설정에서 변경할 수 있습니다.

3. 외부 서비스와 제3자 제공

앱에는 광고 SDK, 외부 분석 SDK, 로그인 기능 또는 사용자 데이터를 전송하는 네트워크 기능이 포함되어 있지 않습니다. 앱에 포함되는 전국 배출 일정은 공공 API 데이터를 배포 전에 정규화한 참조 데이터이며 사용자 정보와 결합되지 않습니다.

4. 보유 기간과 삭제

기기 내부의 사용자 정보는 사용자가 앱을 삭제하거나 설정의 “데이터 초기화”를 실행할 때까지 유지됩니다. 데이터 초기화를 실행하면 배출 기록과 사용자 설정이 기기에서 삭제되고 예약 알림도 취소됩니다. 운영체제나 백업 서비스가 관리하는 백업본의 보관·삭제는 해당 서비스 설정을 따르며, 재설치 시 백업에서 복원될 수 있습니다. 공공 배출 일정과 같은 참조 데이터는 사용자 정보가 아니므로 초기화 대상에 포함되지 않습니다.

5. 아동의 개인정보

앱은 계정을 생성하지 않으며 아동을 포함한 사용자의 개인정보를 외부로 수집하지 않습니다.

6. 방침 변경

앱의 데이터 처리 방식이 변경되면 이 문서를 개정하고 시행일을 갱신합니다.
